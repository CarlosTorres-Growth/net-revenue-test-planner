How it works

Why net revenue per visitor. Conversion rate alone rewards an offer that sells more but gets refunded more. Net revenue per visitor (revenue minus refunds, divided by everyone who saw the page) counts both, so it answers the real question: does B make more money per visitor?

Break-even lift. If B gets refunded more often, it has to convert better just to stand still. The break-even lift is how much better, before any real gain.

Sample size. Each visitor’s net revenue is zero if they don’t buy, or the order value if they buy and keep it. The planner estimates the spread of that number from your conversion rate, order value, order value spread and refund rate, then uses a standard two-sample test to find how many visitors each version needs.

Duration. The test runs in full weeks (at least two) so every weekday is covered equally. You then wait the refund window before reading the result, because refunds from late buyers haven’t arrived yet.

Limits. Results use an estimate of order value spread rather than order-level data, and treat each refund as a full refund. For a final decision on a large test, check the result with order-level data.
